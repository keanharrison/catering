# Untitled UI icon source

Single application icon family: Untitled UI FREE line icons, official @untitledui/icons package (0.0.23), MIT.

User-specified Figma file: https://www.figma.com/design/qhvABQz0X6mfxtQ1PV9Z0Z?node-id=181-128951
Official React source: https://github.com/untitleduico/icons

The Figma connector confirmed the line-icon names and IDs. Its Starter-plan quota was reached during individual design-context exports, so the official free React distribution of the same icon collection is used locally instead of temporary Figma asset URLs. No paid package, upgrade, authentication token or external runtime request is required. The package license is included in node_modules/@untitledui/icons/LICENSE.

components/icons.ts provides semantic aliases so existing interaction logic and icon slots remain intact. mapping.json records every alias. The free collection has no matching robot, chef hat, plug, or cutlery glyph: the corresponding in-file CPU chip, staff user, link, and open menu/book icons are used, rather than adding icons from another library.

Pearl Island’s logo remains its own brand asset. Browser-native affordances remain native.
